# Requirements

## Functional requirements (what the system must DO)
1. REQ-1: The system shall allow users to create and update laundry service orders.
2. REQ-2: The system shall display clear sprint goals, backlogs, and status tracking for tasks.
3. REQ-3: The system shall link each user story directly to a corresponding requirement ID.
4. REQ-4: The system shall allow administrators to view order status and update progress.

## Non-functional requirements (how the system must PERFORM)
1. REQ-5: The system shall load user dashboard pages within 2 seconds under normal network conditions.
2. REQ-6: The system shall ensure user session data is securely stored and authenticated.
3. REQ-7: The system interface shall be fully responsive across mobile and desktop displays.

# User Stories


1. As a developer,I want to have acceptance criteria on each story so that i know that task is fully done.
   - **Requirement:** REQ-1
   - **Acceptance Criteria:**
     -Every story contain testable conditions.
     -Acceptance criteria when a user performs an action so we know the feature works correctly.

2. As a project contributor, I want README to have a clear instruction, so that I can understand the project layout and track sprint milestones easily.
   - **Requirement:** REQ-2
   - **Acceptance Criteria:**
     - README includes overview, structure, and roadmap sections.
     - Sprint milestones are tracked clearly.

3. As a developer, I would like to have numbered requirements attached to each user story so that I can ensure full coverage and traceability of the project's features.
   - **Requirement:** REQ-3
   - **Acceptance Criteria:**
     - Each story explicitly links to a requirement ID (e.g., REQ-1).
     - Traceability between requirements and stories is established.
